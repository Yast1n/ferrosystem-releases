# FerroSystem — Descargas

Instaladores oficiales de FerroSystem para Windows.

Descarga el archivo `FerroSystem_X.Y.Z_x64-setup.exe` de la última versión en la sección **Releases**.
Una vez instalada, la app se actualiza sola cuando se publica una versión nueva.

El código fuente no se publica en este repositorio.
